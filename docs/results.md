# 实测结果、自学习证据与已知问题

这些记录来自同一个实验工位，样本有限。当前可以检查部分任务终态、失败和参数更新机制，尚缺完整的学习曲线、冻结基线比较与独立布局评估。

## 保留的结果

| 检查 | 记录 | 能支持的结论与限制 |
| --- | --- | --- |
| 方块互换 | 一次原始任务在多次保护、修正和断点续跑后完成，终态橙块与灰块离目标约 2.9 毫米和 6.8 毫米 | 支持该次换位终态通过，误差来自图像与桌面标定估计，未得到连续无人介入成功率 |
| 稳定叠放 | 观察到松爪后暂留、退出时被带落和释放时滑落 | 尚未通过夹爪分离、退回后仍稳定的完整验收 |
| 三层叠放分支 | 保留的一轮记录中，橙块抓取为空，第二层与第三层均未通过 | 提供一次失败证据，不能用于估计一般成功率 |
| 视觉过程策略分支 | 保留 9 个实机空中运动试验，包含视觉条件、零潜变量和打乱条件 | 可分析这些轨迹条件，缺少完整训练复现与操作任务评估 |
| 在线 RLS | 发布原实验补偿器及可重复的合成扰动示例 | 可检查在线更新机制，合成示例的误差变化需要与真机效果分别报告 |

换位数值见 [swap_result.json](../evidence/swap_result.json)，三层叠放摘要见 [stack_benchmark.json](../evidence/stack_benchmark.json)，空中运动记录见 [visual_motion_benchmark.json](../evidence/visual_motion_benchmark.json)。当前发布保留数值摘要，原始实验图片和视频未随仓库发布。

三层叠放摘要中的 `status=completed` 表示测试程序结束，该记录的 `layer2_ok` 与 `layer3_ok` 均为 `false`，并记录了空抓原因。

视觉过程策略的末端误差来自标定模型的正运动学，缺少独立运动捕捉测量。抓取和叠放成功率需要对应任务的终态测量。

## 自学习已经有哪些证据

RLS 会根据参考关节位置与实测位置的误差，更新每个关节的补偿权重和协方差。当前类提供内存中的在线更新，尚无检查点保存与加载接口。

叠放流程根据松爪前的画面修正有限范围的落点偏差，并将结果保存到本地 `stack_fit.json`。底座位置变化较大时停用旧修正。当前还缺修正前后在相同条件下的冻结比较。

Qwen 核对指令、物体与叠放结果，使用已有权重推理。当前没有在线微调 Qwen。视觉策略文件提供网络与保护器定义，对应另一个实验分支，尚未公开完整训练数据、冻结权重与重训练命令。

## 距离任务技能自主学习还缺什么

目前的任务流程使用了人为定义的操作阶段、工作区、标定与实测参考姿态。开发中有人工摆回物体和代码调整，未形成逐次完整的介入统计。

以下证据仍待补齐。

- 统一真实交互数据，并能追溯样本参与了哪次策略更新。
- 保存任务策略，重启后加载并复用已经学到的动作选择。
- 在训练未使用的布局上冻结评估，与冻结初始控制器比较。
- 公开全部尝试和失败，统计交互时间、恢复、人工重置与接管。
- 独立检查视觉监督误报，特别是短暂接触、图像重叠与真正支撑的区别。
- 验证自主恢复与重置，使训练可以在限定条件下持续运行。

因此，当前结果支持实验工作台、局部反馈修正和在线补偿机制。零人工任务示范下获得可复用操作策略，仍是后续需要完成并验证的目标，实施路线见 [自学习设计](self-learning.md) 和 [开发路线](roadmap.md)。

## 已知问题

SO-101 固定爪可能在退出时带动已松开的方块。相机支架会遮挡目标。几何预测与带负载的编码器实测位置有差异。实验中出现过 Orange Pi 重启和网络中断。

实际部署还需要统一所有控制入口的控制权与动作审计。当前文件锁只能协调遵守同一锁的进程，其他具有串口访问权限的脚本仍可能绕过它。这也会干扰训练数据对动作来源和结果的归因。
