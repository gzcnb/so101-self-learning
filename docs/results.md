# 实际结果与已知问题

这些记录来自同一个实验工位，统计样本有限。

| 检查 | 记录 |
| --- | --- |
| 方块互换 | 一次原始任务在多次保护、修正和断点续跑后完成，终态橙块与灰块离目标约 2.9 毫米和 6.8 毫米 |
| 稳定叠放 | 尚未通过完整验收，观察到松爪后暂留、退出时被带落和释放时滑落 |
| 三层叠放分支 | 保留的一轮记录中第一轮夹橙块为空，第二层与第三层验收均为失败 |
| 视觉过程策略分支 | 保留 9 个实机空中运动试验，包含视觉条件、零潜变量和打乱条件 |
| 在线 RLS | 发布了原实验中的补偿器及可重复的合成扰动示例 |

数值证据保存在 `evidence/`。三层叠放摘要中的 `status=completed` 表示测试程序结束，需同时检查 `layer2_ok`、`layer3_ok` 和失败原因。

视觉过程策略的末端误差来自标定模型的正运动学，缺少独立运动捕捉测量。它的空中轨迹结果不能用于推断抓取或叠放成功率。

目前任务流程使用了人为定义的操作阶段、工作区、标定与实测参考姿态，开发过程也有人工摆回物体和代码调整。当前证据支持受限反馈修正流程，完全从零人工示范自主获得任务技能仍是开放任务。

## 学习的具体含义

RLS 会更新每个关节的补偿权重，利用参考值与实测值之间的误差估计前馈量。这个模块解决关节跟踪误差。

叠放流程会按松爪前画面修正放置偏差，并将结果保存到本地 `stack_fit.json`。这是有限范围的参数更新。Qwen 核对指令、物体与结果。

视觉策略文件提供网络与关节保护器定义。它对应另一个实验分支。当前发布没有提供完整的策略训练数据、冻结权重或重训练命令，因此这一分支以源代码与数值记录供审查。

## 需要继续解决

SO-101 固定爪可能在退出时带动已松开的方块。相机支架会遮挡目标。几何预测与带负载的编码器实测位置有差异。Orange Pi 曾出现重启，控制过程中网络也会中断。

实际部署还需要统一所有控制入口的控制权与动作审计。当前文件锁只能协调遵守同一锁的进程，直接从其他脚本写入串口仍可能绕过它。
