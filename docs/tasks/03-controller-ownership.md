# 统一机械臂控制权与动作审计

## 要解决的问题

实验期间，网页以外的 SSH 脚本也能直接驱动舵机。现有文件锁只能协调遵守同一锁的入口。自主学习需要明确每次动作的来源，避免多个执行者相互干扰，也避免把外部动作造成的结果误记成策略的学习经验。

## 需要实现

- 建立统一板端控制入口，网页、训练器和研究脚本通过同一入口提交动作。
- 定义执行权的获取、释放、过期和恢复规则，处理重复请求，明确陈旧请求的拒绝条件。
- 每次动作记录任务编号、发起者、程序与策略版本、参数摘要、时间、实际执行和结束原因。
- 保留板端关节、工作区、步长与运行状态检查，学习策略和大模型共用这些检查。
- 控制连接异常后核对执行状态与现场，避免重连时无条件重新执行。
- 明确部署边界，限制绕过统一入口直接写串口的路径。记录仍能绕过控制的权限与限制。

## 验收

- [ ] 覆盖同时启动两个控制器、重复提交、任务重试和陈旧请求。
- [ ] 覆盖进程退出、SSH 断线和设备重启，说明每种情形下执行权与动作状态。
- [ ] 相机预览和只读遥测不会使能扭矩。
- [ ] 每次真实动作可追溯到任务和发起者，训练数据能关联实际执行结果。
- [ ] 提供接管、停止与异常恢复方法，说明停止动作的实际生效条件和延迟。
- [ ] 明确同一系统中拥有串口直接访问权限的其他进程是否仍能绕过入口。

此任务为持续真机训练的前置基础设施。现有文件锁不构成所有硬件入口的统一控制权。
