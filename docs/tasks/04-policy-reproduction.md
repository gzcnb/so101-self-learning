# 发布视觉过程策略的可复现训练流程

## 要解决的问题

当前代码包含 CNN 过程编码器、GRU 关节策略与保护器定义，以及 9 段空中轨迹试验摘要。完整训练流程、原训练数据和可复用权重尚未随本仓库发布。

该分支需要先复现其自身的学习与评估，再检验对操作任务的帮助。空中轨迹误差只支持对应运动实验的分析。

## 需要实现

- 说明数据来源、采集条件、许可、是否包含人工或生成轨迹，明确学习目标与已有先验。
- 发布训练入口、配置、随机种子、依赖版本、数据分割和运行命令。
- 提供冻结策略导出、权重校验与离线推理方法，记录模型适用的状态和动作范围。
- 在相同评估协议中保留视觉条件、零条件和打乱条件，说明它们分别检查什么。
- 发布全部试验结果和失败，区分标定模型正运动学估计与独立物理测量。
- 如与任务学习结合，说明交互数据和奖励如何进入 #1 的统一闭环。

## 验收

- [ ] 能从许可明确的数据按文档重建模型，或说明原数据缺失时哪些结果无法复现。
- [ ] 能加载公开权重，运行冻结策略的离线推理检查。
- [ ] 按预先定义的真机协议报告全部试验、测量误差、失败与人工介入。
- [ ] 如果宣称改善抓取或叠放，提供对应任务的独立评估及冻结基线。
- [ ] 零人工示范实验的数据与含人工示范的实验分开报告，避免混用结论。
