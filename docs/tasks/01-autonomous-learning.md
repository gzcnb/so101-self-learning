# 从真实经验更新任务策略

## 要解决的问题

项目希望让 SO-101 从自己的真实尝试中获得可保留的动作改进，逐步减少逐个任务的人工教学和调参。当前 RLS 更新关节补偿，叠放流程保存有限的放置偏差。任务流程仍由人工编排，统一经验库、任务策略训练和独立评估尚未接通。

本任务需要交付可运行的经验采集、模型更新、保存恢复和评估闭环。设计依据见 [自学习说明](https://github.com/gzcnb/so101-self-learning/blob/main/docs/self-learning.md)。

## 第一版范围

先固定一个任务、工位和初始控制器，在现有原语内学习少量动作参数。可从抓取偏移、释放高度、分离距离及已检查的退出路径选项中选择，明确各参数单位、范围和有效条件。

先实现有边界的参数搜索基线，再评估视觉残差策略或离策略强化学习。交付说明必须列出采样方法、更新规则、探索预算及哪些行为仍由人工规则决定。

训练数据来自机械臂自己的尝试。预训练视觉语言模型、标定与原语作为先验列出。人工成功轨迹、遥操作接管与人工重置分别记录。

## 需要实现

- 定义带版本的回合格式，关联图像、关节状态、请求动作、实际动作、结果、失败原因、时间与人工介入。
- 将 Qwen 的目标核验与后续阶段监督关联到原始证据，设计无法确认状态，检查监督误报。
- 明确阶段反馈与完整任务奖励。完整叠放以夹爪分离、机械臂退回后仍稳定为依据。
- 保存失败、保护中止和通信中断，注明各类样本能否参与更新及相应处理。
- 提供真实环境交互接口、训练命令、经验索引、模型版本、随机状态和恢复命令。
- 通过统一板端执行入口调用动作，记录恢复条件和重置需求。控制权改造依赖 #3。
- 保存候选策略的适用条件与基线版本，评估通过后采用，保留回退能力。

## 验收

- [ ] 能从干净环境按文档运行交互与训练命令，提供数据格式和示例回合。
- [ ] 能追溯一条真实经验到一次实际模型更新，保存更新前后的版本。
- [ ] 停止并重启进程后，恢复训练状态和已学模型，复现模型的动作选择。
- [ ] 预先固定布局范围、试验数量、停止规则、回合限制与成功判据。
- [ ] 在独立布局上冻结候选策略，与冻结初始控制器使用同一协议比较，明确在线适应是否关闭。
- [ ] 报告成功数、总尝试数、统计不确定性、真实交互时间、恢复、人工重置与接管次数。
- [ ] 一句话再次调用时重新识别现场，记录已保存模型的使用及适用条件检查。
- [ ] 同时保留失败和无法确认的评估证据，合成、仿真与真机结果分别报告。

第一版如需人工重置，必须明确这一训练条件。完全无人重置的连续训练作为后续阶段验收，不能在该能力完成前宣称已经实现。
