# 开放任务

| 优先级 | 任务 | 验收结果 |
| --- | --- | --- |
| 高 | [从经验更新任务策略](tasks/01-autonomous-learning.md) | 给出真实训练入口、可恢复的数据与策略检查点、独立评估 |
| 高 | [稳定叠放](tasks/02-stable-stacking.md) | 松爪和机械臂退回后，两块仍稳定叠放，按预先定义的协议统计 |
| 高 | [控制权与动作审计](tasks/03-controller-ownership.md) | 所有硬件入口共享控制权，能追溯每次动作来源 |
| 中 | [视觉策略重训练](tasks/04-policy-reproduction.md) | 从公开数据重新训练并复现实机轨迹评估 |

当前发布将几何控制、参数补偿和网络定义分别保留在对应代码中。后续改进需保留相同测试条件、失败样本和恢复记录。
